Password Management System (Java)
The Password Management System is a Java-based desktop application developed during the Semester 3 vacation as an academic learning project.
The system is designed to securely store, retrieve, update, and manage user passwords using Core Java and Java Swing.

The primary goal of this project was to understand Java fundamentals, file handling, basic security concepts, and desktop application development.

🎯 Project Scope

Desktop application built using Java Swing

Backend logic implemented in Core Java

Local storage using file handling

Basic password encoding for security

Menu-driven and user-friendly interface

🖥️ User Interface Note

The application uses a simple Swing-based UI, as it was developed during an early academic learning phase (Semester 3 vacation).
The focus was on:

Java OOP concepts

Event handling

Logic implementation

UI and backend interaction

Advanced UI design and theming were not the objective.

✨ Features

🔐 Add new passwords

👁️ View stored credentials

✏️ Update existing passwords

🗑️ Delete saved entries

🔒 Passwords stored in encoded format

💾 File-based data persistence

🧭 Simple menu-driven workflow

🛠️ Tech Stack

Java

Java Swing

Core Java

File I/O

🔐 Security Note

Passwords are not stored in plain text

Basic encoding/hashing is used

No hardcoded sensitive information

Designed for learning purposes only
